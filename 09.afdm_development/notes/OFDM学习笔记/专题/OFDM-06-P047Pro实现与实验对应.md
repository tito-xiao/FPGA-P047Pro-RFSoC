# P047Pro 上的 OFDM 实现与实验对应

主笔记：[[01-OFDM入门与实现过程]]。

## 各部分负责什么

| 部分 | 在厂家示例中的作用 |
|---|---|
| ARM / PS | 运行 Linux、PYNQ、Python 和 Jupyter |
| FPGA / PL | 按已加载设计执行高速 OFDM 收发数据处理 |
| RFDC | ADC/DAC 转换与配置好的数字混频、插值/抽取等处理 |
| DMA | 在观察接口与处理器内存之间传送采样 |
| 浏览器图表 | 展示采集结果与控制项 |

TX4→RX2 是本项目 OFDM 回环的目标路径。多个子载波合成在同一个物理通路的信号里，具体 RFDC 格式、时钟和频点由当前硬件设计决定。

## 调制下拉框为什么会改变星座

本地厂家 `ofdm.py` 的调制设置器把所选方案写入发射核控制寄存器：QPSK 编号为 1、16-QAM 为 3，寄存器偏移为 `0x100`。这表明 Python 在控制既有硬件配置；真实数据通路还要依据 HDL/设计进一步核对。

## 三种图分别在哪里理解

| 图 | 理解方式 | 本项目需要注意的地方 |
|---|---|---|
| 时域图 | I/Q 采样随时间的变化 | 观察点可能在插值或其他处理前后 |
| 频谱图 | 信号在频率上的分布 | 原截图纵轴为相对归一化 dB，不能直接作为绝对 dBm |
| 星座图 | 相应观察点的复数符号分布 | 已保存数据来自接收处理后的星座观察点 |

## 已有实验与证据

以下内容来自 2026-11-17 用户反馈和截图，本笔记没有新增板上测试。

- 选择 QPSK 后，观察到四个点簇。
- 选择 16-QAM 后，观察到十六个点簇。
- 两种调制各保存 1024 个复数样本，重新加载和绘图，比较保存前后数据为 `True`。
- OFDM 的 03 综合界面已显示发射频谱与 16-QAM 接收星座。

保存的 1024 个星座样本不应直接当成 1024 个 OFDM 符号，也不应作为原始 ADC 波形。它们支持基础星座观察与文件一致性；发送/接收比特 BER、完整帧统计及三轮独立初始化仍需相应证据。

## 从软件到硬件的实现顺序

1. 浮点模型：已知比特、调制、子载波分配、IFFT/FFT、CP，比较恢复比特。
2. 信道模型：噪声、多径、未知定时、频偏；加入同步、导频、估计与均衡。
3. 定点模型：明确位宽、缩放、舍入和饱和，逐级比较浮点与定点结果。
4. RTL 仿真：检查计算结果、缓冲、帧边界、握手和停顿行为。
5. 板级集成：时钟、复位、RFDC 格式与速率、跨时钟域、DMA 与寄存器。
6. 板上验收：已知数据比较、丢样/溢出统计、时序与独立初始化复现。

> [!info] 当前项目边界
> 项目已有 AFDM 软件基准和功能 RTL 仿真记录。真实 AFDM 射频、完整实时 FPGA 收发与时序验收仍未完成；目标器件综合存在 Vivado 许可缺失问题。普通 OFDM 的 FFT 核心教学实验与这些整机验收分开记录。
