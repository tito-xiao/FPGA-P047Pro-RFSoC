## 2. 采集的是什么

采集接口为：

```python
ofdm_hw.inspectors['constellation'].get_frame()
```

它返回接收处理后的复数星座数据。驱动从交错 int16 I/Q 按 `2^-14` 组成复数值。本次没有读回确认该观察点的有效采样率，不能直接把它标为原始 ADC 数据或填入 ADC 采样率。

## 3. 已归档 Notebook 中的采集代码

下面代码取自现有电脑归档的 `02_rfsoc_ofdm_demonstrator.ipynb`，是历史操作的留存。它依赖当时内核中已初始化的 `ofdm_hw`；写笔记时没有再次在板上执行。

复现时先在界面选择目标调制，停止图表自动刷新并等当前采集结束，再运行采集代码。代码从硬件对象读取当时的实际调制方式，为两种调制建立不同的新目录。

```python
from pathlib import Path
from datetime import datetime
import numpy as np
import json

mod = ofdm_hw.ofdm_transmitter.modulation
out = Path.home() / "jupyter_notebooks" / "ofdm_captures"
out = out / (datetime.now().strftime("%Y%m%d_%H%M%S_%f") + "_" + mod)
out.mkdir(parents=True, exist_ok=False)

iq = ofdm_hw.inspectors["constellation"].get_frame()
np.save(out / "iq.npy", iq)

meta = {
    "modulation": mod,
    "capture_point": "receiver constellation",
    "samples": int(iq.size),
    "tx_gain": float(ofdm_hw.ofdm_transmitter.gain)
}
(out / "meta.json").write_text(json.dumps(meta, indent=2), encoding="utf-8")

print("保存位置：", out)
print("调制：", mod)
print("样本数量：", iq.size)
```

`Path.home()` 对应运行 Notebook 的用户家目录。历史保存输出使用 `/root`，而后续 AFDM 的用户输出使用 `/home/xilinx`；本笔记分别保留原路径，不推定两者是同一个目录。

## 4. 已归档的重新加载与绘图代码

```python
import matplotlib.pyplot as plt

saved_iq = np.load(out / "iq.npy")

print("样本数量：", saved_iq.size)
print("保存前后完全一致：", np.array_equal(iq, saved_iq))

plt.figure(figsize=(5, 5))
plt.scatter(saved_iq.real, saved_iq.imag, s=5)
plt.axis("equal")
plt.xlabel("I")
plt.ylabel("Q")
plt.title(mod + " - saved data")
plt.grid(True)
plt.savefig(out / "constellation.png", dpi=150)
plt.show()
```

其中 `iq` 是刚取到的内存数组，`saved_iq` 是从文件加载的数组。`np.array_equal` 为 True，说明这两个数组在当次比较时一致，不能直接推出发送与接收比特都正确。
