## 发布工具和结果

`scripts/export_github_project.py` 使用 Python 标准库生成公开副本。`--root` 指向主目录，`--output` 必须是活动仓库 `artifacts` 下的空目录；非空输出目录会被拒绝，不会递归删除已有数据。

本次输出为 `artifacts/github-publication-20261118/snapshot-ready`。副本中 `PUBLICATION_MANIFEST` 保存文件清单、原文件和已发布文件的摘要、文本替代统计及附件链接改写记录；旁边的 `snapshot-ready-verification.json` 保存本机完整性检查结果。

文件清单的原 SHA-256 用于核对本地原文件；`.placeholder.md` 的摘要只对应说明文本。被整体排除的缓存不计算逐文件摘要，私人资料不列出内部文件名或摘要。

Markdown 中指向未发布原文件的附件链接只在副本里改为对应说明；原始 Markdown 保留。现有笔记中的非标准 Obsidian 链接、外部网站和绝对本机路径不视为已验证的公开下载链接。
