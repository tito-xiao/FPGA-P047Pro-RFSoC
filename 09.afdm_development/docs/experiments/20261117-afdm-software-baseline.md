# AFDM 软件初版验证

## 目标与预期

按用户要求快速从已完成的 OFDM 演示进入 AFDM，建立路线 §8.1 的软件起点；OFDM 的硬件复现与 BER 缺口继续保留。

## 版本与环境

- 日期：2026-11-17；分支 `dev/xiao`，本次未提交或推送。
- 执行位置：本机 Windows，Codex Python 运行时，NumPy 2.3.5。
- 入口：`notebooks/02_afdm_software_baseline.ipynb`。
- 约定：[原论文 §II-B、§III-A/C](https://arxiv.org/html/2204.12798v2)，采用单位化 FFT/IFFT。

## 参数与方法

- N=64，512 个 QPSK 块，65536 比特，随机种子 20261117。
- c1=1/(2N)，c2=sqrt(2)/N²；本轮仅为变换与 AWGN 自检用例。
- SNR=0、2、4、6、8、10 dB，定义为 Es/N0。Es=1，复噪声方差 1/SNR。
- AFDM 与 OFDM 使用相同比特、块长、平均功率和时域噪声样本。
- 直接构造完整 DAFT 矩阵，独立对照 FFT 实现的正负号、索引和归一化。
- 无时延 AWGN 模型，未包含前缀、导频或厂家 OFDM 的具体帧结构。
